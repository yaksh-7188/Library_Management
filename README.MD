# Library Management System (Java JDBC)

A console-based Library Management System built with Java, JDBC, and MySQL.

## Features
- Add new books
- View all books
- Update book price
- Delete book by ID

## Project Structure
- `src/com/library/model`: Model Classes
- `src/com/library/dao`: Data Access Object
- `src/com/library/util`: Database Utility
- `src/com/library/Main.java`: Application Entry Point

## Setup
1. Run `schema.sql` in MySQL.
2. Update database password in `DatabaseUtil.java`.
3. Run `Main.java`.
